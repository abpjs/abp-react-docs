# v2.1.1

**Release Date:** February 2026

This patch release updates the Pro packages to align with the latest ABP Commercial backend module versions. No functional changes are included.

## Highlights

- **Pro Package Alignment** - All Pro packages updated to align with ABP Commercial v2.1.1 backend dependencies
